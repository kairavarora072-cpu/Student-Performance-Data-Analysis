# Student Performance Data Analysis
Data Science mini-project using Pandas, NumPy, Matplotlib and Seaborn.

## Objective
Investigate factors associated with student academic performance, including attendance, study hours, subject marks, gender and category.

## Run
pip install -r requirements.txt
python student_performance_analysis.py

## Dataset
The dataset is synthetic and created for academic demonstration. It includes intentional missing, duplicate and inconsistent records to demonstrate data cleaning.
